# envx website

Marketing + docs site for [envx](https://github.com/envx-project).

- Vite + TanStack Router (file-based, type-safe, prerender-ready)
- Tailwind v4 + shadcn-style components
- Static SPA, deploys to Cloudflare Pages

## Develop

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
bun run preview
```

## Deploy

See `SETUP.md` for first-time Cloudflare Pages setup.
